# Ansible Github
A Ansible role for installing and configuring Github's cli tool.

Built around installing the Linux version of Github's cli tool `gh`

Official documentation [link](https://github.com/cli/cli/blob/trunk/docs/install_linux.md).

## Signing

The signing key can be gotten from [source](https://cli.github.com/packages/githubcli-archive-keyring.gpg)
